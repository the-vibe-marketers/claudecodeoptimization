### 1️⃣ **Use the Cheap Model First**
**What:** Use Haiku for 80% of your work
**How:** Setup defaults to Haiku automatically. Done.
**Outcome:** Spend 5x less money while getting results just as fast
**Example:** Fix bugs, read code, simple edits = Use Haiku ($0.80 per session)

---

### 2️⃣ **Search Before You Read**
**What:** Always search for what you need first
**How:** Type "search for X in file" instead of "read file"—saves 95% cost
**Outcome:** Find answers 95% faster and cheaper on large files
**Example:** Looking for an error? Search "ERROR" instead of reading entire 50MB log

---

### 3️⃣ **Read Files in Chunks, Not All at Once**
**What:** Read large files in small pieces (50KB at a time)
**How:** Say "read lines 1-100" instead of "read entire file"
**Outcome:** Reduce costs from $10 per file to $0.10
**Example:** Reading a 10MB file? Break it into 200 tiny reads = 100x cheaper

---

### 4️⃣ **Do Multiple Tasks at Once**
**What:** Ask Claude Code to run 5 tasks in parallel
**How:** Say "run these in parallel" when giving multiple independent tasks
**Outcome:** Finish faster AND save money simultaneously
**Example:** Read 3 files together instead of one-by-one = Same cost, 3x faster

---

### 5️⃣ **Use the Expert Agent for Exploration**
**What:** Use Explore agent when learning unfamiliar code
**How:** Say "explore this codebase" instead of doing random searches
**Outcome:** Find what you need 60% faster without trial-and-error
**Example:** New codebase? Let Explore agent map it automatically

---

### 6️⃣ **Plan Major Changes Before Starting**
**What:** Spend 2 minutes planning before big refactoring
**How:** Say "create a plan for refactoring X" before you start coding
**Outcome:** Prevent 2+ hours of wasted rework ($50 saved)
**Example:** Changing 5+ files? Get a plan first—costs $0.50, saves $50

---

### 7️⃣ **Turn On Budget Alerts**
**What:** System warns you at 70% and 90% of your monthly budget
**How:** Run setup.sh once—alerts turn on automatically
**Outcome:** Never overspend again
**Example:** Budget is $100? Get warned at $70 and $90 automatically

---

### 8️⃣ **Limit Search Results**
**What:** Ask for "top 50 results" instead of "all results"
**How:** Say "find first 50 matches for X" instead of "find all matches"
**Outcome:** 10x cheaper when searching large codebases
**Example:** 10,000 search results = $5. Top 50 results = $0.50

---

### 9️⃣ **Be Specific in Your Requests**
**What:** Ask clearly exactly what you need
**How:** Include file name, line number, and exact problem in one sentence
**Outcome:** Get better answers + spend 30% less
**Example:** Good: "Fix the login bug in auth.ts line 45"
**Bad:** "Help me fix this" (costs more, unclear)

---

### 🔟 **Use Quick Shortcuts for Folders**
**What:** Save your project paths as shortcuts
**How:** Setup creates shortcuts automatically—just type @utils instead of full path
**Outcome:** Work faster, make fewer mistakes
**Example:** Type `@utils` instead of typing the full folder path every time

---

### 1️⃣1️⃣ **Create a Task Checklist at the Start**
**What:** For multi-step work, list all tasks first
**How:** Say "create a todo list for X" at the beginning of any project
**Outcome:** Don't forget steps, finish 40% faster with fewer mistakes
**Example:** Large project? Create checklist before you start

---

### 1️⃣2️⃣ **Read Smart: Limit How Much You Load**
**What:** When reading files, tell Claude Code to read only part of it
**How:** Say "read lines 100-200 from database.ts" instead of "read the whole file"
**Outcome:** Costs pennies instead of dollars per large file
**Example:** Instead of "read entire database.ts" → "read lines 1-100"

---

### 1️⃣3️⃣ **Don't Ask the Same Question Twice**
**What:** Claude Code remembers everything in your session
**How:** Just reference previous results—"use the errors we found earlier"
**Outcome:** Don't re-do work, automatically save money
**Example:** Already searched for "ERROR"? That result is cached for free

---

### 1️⃣4️⃣ **Let the System Filter Data for You**
**What:** Let Claude Code clean/filter data before showing you
**How:** Say "find and show only X from Y data" instead of "show all data"
**Outcome:** Get only what you need, 95% less cost
**Example:** 10,000 rows of data? System shows you only 5 relevant rows
